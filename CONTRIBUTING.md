# Contributing to mcpsmiths

Thanks for taking the time to contribute! This guide applies to every repo in
the mcpsmiths org unless a repo has its own `CONTRIBUTING.md` that overrides it.

## Before you start

- For a small fix (typo, docs, one-line bug fix), just open a PR directly.
- For anything larger, open an issue first describing the change so we can
  agree on the approach before you invest the time.

## Making a change

1. Fork the repo and create a branch off `main`.
2. Make your change, keeping it focused — one logical change per PR.
3. Run the test suite (`pytest`) and make sure it passes.
4. Update docs/README if behavior changed.
5. Open a PR describing **what** changed and **why**.

## Response times

Expect an initial response (review, question, or acknowledgment) within
**48 hours**.

## Proposing a new MCP server for this org

Open a [discussion](https://github.com/orgs/mcpsmiths/discussions) describing
the tool or backend you'd want an MCP server for. See the
[org profile README](https://github.com/mcpsmiths/.github/blob/main/profile/README.md#adding-your-own-mcp-server-here)
for what a good fit looks like.

## Reporting a security issue

Do **not** open a public issue for a security vulnerability — see
[SECURITY.md](./SECURITY.md).
